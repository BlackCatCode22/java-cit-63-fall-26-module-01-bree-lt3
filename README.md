Getting Started with Java

Read and Study Chapter 1 in our textbook. Chapter 1 introduces the Java programming environment, the Java Virtual Machine, the basic building blocks of programs, and object-oriented programming.

Then begin Chapter 2: Names and Things as you work through your first Java programs.

Set Up Your Java IDE

Make sure your IDE is configured and that you can create, compile, and run a Java program.

As you complete each program:

Create the program in your IDE.
Run and test it.
Commit your work locally with Git.
Push your work to your GitHub Classroom remote repository.

Remember: saving your program is not the same as committing it, and committing it is not the same as pushing it to GitHub.

Code the textbook's first Java program from Section 2.1.

Programming Challenge — Largest of Three Integers

Now write your own program that asks the user for three integer values and determines which value is the largest.

IDE Project: largestOfThree
Class: LargestOfThree
Source file: LargestOfThree.java

Your program should:

Use Scanner to obtain three integers from the user.
Store the values in appropriately named variables.
Determine the largest value.
Clearly display the result.
Follow our CIT-63 Java Style Guide.
Use camelBackStyle for variables and PascalStyle for the class name.
Include braces and proper indentation.

When your program is working:

Save → Test → Commit → Push

Don't forget to verify that LargestOfThree.java actually appears in your GitHub Classroom remote repository.
